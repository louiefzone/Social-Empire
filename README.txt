SOCIAL EMPIRE — BETA 0.1.1

1. Double-click index.html to play.
2. Click CREATE POST.
3. A post takes time to produce, then becomes active.
4. Refresh/check the active post to see its performance.
5. Buy upgrades with cash.
6. Your save is stored in this browser.

This is a deliberately simple first playable beta. It is designed for testing the game loop, not final balance.
